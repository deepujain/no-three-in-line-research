The general ingredients are classical bipartite matching, MRV backtracking and exact integer geometry; no novelty is claimed for them. The paper/database context comes from the existing2026-11-26 literature audit, not a new external search.

The current source-local record makes a small change unpromising as a distinct construction region: target157 at most8 source deletions has scoped native UNSAT;9..12 deletion SAT timed out; short connected-path patches and published-seed repairs through5 are closed only in their stated families. ## Exact constructive search

Use one occupancy bitset for cells known unsafe because they lie on a line through two selected points. At the root enumerate all choose(78,2)=3003 pairs of R. Normalize their integer direction by gcd and visit all in-bounds lattice cells along that line, marking their board bits. No floating slope arithmetic or modular wrapping is used. A proposed new cell outside B union S is safe exactly when it is not in this union of secant lines. Points already selected never reenter a domain.

The static row domain consists of cells outside B union S and outside the retained secant mask. Build the79 by79 allowed-cell bipartite graph and run one deterministic maximum matching as a necessary root feasibility gate. If matching size is below79, save its primal matching and equal-capacity min-cut or equivalent standard alternating-reachability Hall certificate, then stop this exact anchor family without DFS. A complete root domain census plus verified Hall certificate proves only this fixed retained-anchor/source-disjoint family cannot complete. If all79 rows match, save that combinatorial assignment as feasibility evidence only; it need not satisfy interactions among its new cells and is not a geometric incumbent.

If the root gate passes, perform deterministic depth-first construction of M. Select an unassigned row with the smallest current domain after excluding used columns and the current secant mask; break ties by row coordinate. Try allowed columns in increasing order. Zero domain prunes the current partial assignment. On inserting p, add lines through p and each previously selected point in R union X to the unsafe bitset, mark its row assigned and column used, and recurse. Store the old bitset/column mask in the stack for exact backtracking. Retained points and earlier matching points stay fixed within a branch. This incremental rule adds precisely all newly formed pair secants, so every partial R union X is valid by induction; triples with one, two or three new cells are all handled. The solver searches compatible assignments, never an invalid-score energy landscape.

No complete matching is assumed from a greedy choice, and the root matching is only a necessary bound. The DFS may backtrack and is complete for this one anchor family only if its stack actually exhausts without any cap/timeout. MRV and ascending column order are deterministic; no RNG, SAT, unbounded beam, global visited set, learned-cut pool, external optimizer, partial restart or repeated warm walk is used. Exactly one retained anchor and one run are proposed.
