# Guarded fast diagonal DFS

The opt-in `--diagonal-secant-fast-guard` delegates to `research/diagonal_secant_fast_guard.py`, which runs the separately reviewed fast core in a new owned process group. It gives the approved `research/owned_process_guard.py` helper the remaining part of the parent CLI's 30-second maximum after setup, and the unchanged sampled 256 MiB parent-plus-owned-process limit. The helper controls monitoring and cleanup; a guard, monitor, cancellation, source, or cleanup failure overrides a child completion. The CLI catches SIGTERM and supplies the helper's cancellation callback. Limits are sampled and cleanup or host operations can overrun the nominal deadline; the helper's process-ownership assumptions and limitations apply.

Source binding covers the fast and original DFS cores, original guard, verifier, new guard, cleanup helper, and shared entrypoint. Hashes are checked before the worker imports the core, before each verified witness is atomically published, after search, and by the guard at the end. The checks do not prevent an adversarial change and restoration between hash checks. A fresh witness directory is published in the initial incomplete report. A successful search reports only declared main-diagonal-reflection slices; it does not establish unrestricted infeasibility.

The combined test command for fast guard, fast DFS, original guard, cleanup helper, old dispatcher and SAT tests passed 56 tests with one skip. Integration tests use real tiny DFS worker processes at n=3 and n=5 but mock the guard helper, covering dual-verified witnesses, source binding, external failure overriding already-published completion, cancellation forwarding and atomic witness-before-terminal ordering. The CLI route also completed n=3 and n=5 with the helper mocked and real DFS workers. These do not establish real-host RSS or cleanup behavior; the lead ran separate real-host helper gates, and real-host fast CLI checks and independent integration review remain required. No n=79 run or numerical benchmark was performed.
