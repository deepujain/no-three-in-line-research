# Score-11 paired three-edge rotation proposal

This is a design for review, not an authorization to implement or run. The source is the preserved invalid full state with 11 triples and normalized hash `f0ab1e9b47f89b8252eb5fec00b6d2b451bd25545924dc4a491d0b6638dff34d`. Its three audited minimal conflict covers through size five each contain (33,78) and (78,78). These share a column, so any proper decomposition of the degree-two incidence graph puts them in opposite matching colors.

Use one fixed deterministic decomposition. In each matching, rotate three entries simultaneously: one of its anchor rows plus two rows selected from the rows of the 23 original conflict-incident points; try both three-cycle orientations. Test occupancy against the combined final matchings, not an intermediate state. Each matching remains a permutation; reject duplicates between matchings. These paired rotations are distinct from prior one-matching pair/triple moves, and can cross a barrier that prevents a useful single intermediate move. The reviewed fixed source has 21 distinct incident rows; excluding each anchor leaves 20 choices per side. Exactly 4 × C(20,2)² = 144,400 combinations are streamed for this chosen decomposition and incident-row restriction. This is an upper bound, not a runtime or RSS measurement. No visited history is needed.

Compute the *effective* removed set D = S minus T from the resulting point sets; simultaneous cross-color replacements can cancel raw removals. For a full valid 158-point T, every original conflict triple must intersect D. For a 157-point result T minus {p}, if any original conflict triples survive in T, p must be in their common intersection; if none survive, p may be any point in T, including an added point. In either case p must also hit every new conflicting triple in T; dual-verify any proposed final result. If the separately pending full cap-five repair is completed and independently accepted as negative, it excludes outputs whose total effective deletions from S are at most five. The 157 effective deleted set may additionally contain the final removed retained source point, so an unconditional prune based on six raw removed edges is unsound. No cap-five closure is claimed here.

The restriction to one decomposition and incident rows covers only a small neighborhood, not all six-deletion repairs or all half-turn states. A tiny/source review and bounded conflict-incidence survivor census would be required before a separately authorized host run; drop the idea if no survivors or projected work exceeds its time and 256 MiB guard. No success or improvement is assumed.
