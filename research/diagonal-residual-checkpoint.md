# Separate residual-bound checkpoint core

This is the first core-only stage of approved design `e81a8a123daf8b26330587ed2a088db352b6c98cd7e2d94e78ff3d67ff4db2aa`. `research/diagonal_residual_checkpoint.py` derives from the frozen row-batch checkpoint while keeping its batch transactions, local frame/cursor loop, witness checks, bounded input, source/predecessor checks and publication behavior. New code supplies the complete residual scan and physical-work diagnostics. No residual guard, chain or shared dispatcher route is implemented.

The new exact format is `diagonal-residual-rowbatch-frontier-v1`, with the unchanged batch-order tag and explicit `residual-row-degree-component-parity-bipartite-sum-v1` prune policy. The source manifest binds this core and both tiny references plus the frozen geometry/checkpoint/verifier dependencies. Old schemas and source bindings are rejected. A new absent checkpoint starts with zero counters and no predecessor; no old history is migrated or credited.

Each scan validates n2..79 before bounded scratch allocation, checks the complete canonical orbit declaration, computes admissibility once per orbit and retains a byte mask, row degrees, adjacency bitsets and sum-color bitsets. Positive-demand isolated rows remain vertices. A completed scan applies the five reviewed necessary conditions. Full row states use the existing leaf path; surviving prefixes use the exact original MRV row and lexicographic unordered batch order. Timeouts propagate before any partial verdict; graph work does not mutate geometry. The inherited secant transactions remain unchanged.

Per-invocation physical diagnostics separate reconstruction from traversal, with checked unsigned-64-style counters for scan attempts/completions, edge tests, graph steps, candidate checks and overlapping rule hits. They are not serialized as historical tree nodes. Reconstruction, traversal and final validation/publication timings are reported separately; setup/import and the future whole-process measurement must not be inferred from their sum. The inherited source reads, encoding and atomic publication are not cooperatively interruptible, and no core-only result establishes a hard wall or memory gate. A future reviewed guard must reject late publication and distinguish published from accepted hashes.

Eight tests pass (0.965 seconds on the frozen evidence run). The production scan is checked through the independent n2..5 all-subset/all-completion-superset determinant oracle. Repeated quotas 1, 2 and 5 exactly match uninterrupted terminal logical state and slice counts, with 19/64/192 nodes and 4/10/16 witnesses for n3/n4/n5. Every emitted witness sequence agrees with the frozen tiny order. Terminal payloads agree after removing the necessarily different predecessor field; physical replay work never increments logical counters.

Fault coverage includes 681 injected deadline boundaries across 17 representative n5 prefix shapes selected by violation set, odd-cycle presence, nonempty prefix and leaf status. Shapes include component-parity and color-shortage cases as well as passing and full states. Every interruption leaves the geometry snapshot unchanged and returns no partial candidate list. Additional tests cover existing-checkpoint reconstruction timeout without byte replacement or new logical nodes, pending-genesis timeout, exact slice declarations, source/policy/counter/cursor tampering, old-schema rejection, wrong external hash, relocation, oversized/malformed input, work-counter overflow, and exceptions before/after publication and during the witness callback.
