# Independent nonuniform-insertion source and synthetic review plan

This plan concerns the single proposed insertion branch. It does not authorize an actual n74 source load, target insertion, census, or search. The authenticated actual source can remain unread until Root separately allocates its use.

## Separate expected geometry

`research/nonuniform_insertion_independent_tiny_oracle.py` imports only the Python standard library. For n=2,3,4 it enumerates all two-column choices in each row, retains exactly those with column loads two, and applies direct integer determinants to certify the original source. This covers every full-axis valid set without using production support choices, thresholds, masks, or line clipping. A target is built using coordinate alphabets with the inserted row/column omitted, rather than the worker's threshold-shift formula. All target triples are scored by direct determinants; conflicts are then separated by whether the last index is the new point.

Expected candidate sets remain Python sets of literal `(column_gap,row_gap)` pairs. They include all gaps for the oracle, with the four both-boundary cases marked excluded. Every emitted candidate bit from a production result will be decoded directly and compared with the relevant literal set; excluded bits must never appear in an accepted candidate or certificate collection. Boundary and nonboundary outcomes are not conflated.

The independent certificate predicate reconstructs mapped source indices, checks cardinality and uniqueness, confirms exclusion policy and membership, and evaluates the exact determinant. The oracle supplies both old-triple and new-point/pair obstructions. A worker may choose any valid first obstruction: it need not reproduce the oracle's iteration order.

## Production comparison once an interface is frozen

For every synthetic source and included gap, compare the final unexcluded set with the direct target validity set. Where the worker exposes class masks, compare old-triple and new-point/pair masks separately, including cases obstructed by both classes. Require exact coverage-union equality. Verify the first-obstruction certificate for every removed gap independently. For an early all-covered return, prove that every included gap has a surviving valid certificate; do not require full score counters. For any incomplete run, reject a positive interpretation of unexcluded gaps. If a production helper stops early, its partial class masks must not be mislabeled complete.

Rectangle mask tests compare every interval pair on each small gap grid against direct Cartesian enumeration, including single cells, whole rows/columns, first/last intervals, and the four excluded corners. The bit-index convention must be independently checked on asymmetric coordinates. No expected mask is generated by the same multiplication or shifts used by production rectangle construction.

Line tests enumerate endpoint pairs in [-1,2]^2 and every nonempty rectangular interval on [-1,3], in both endpoint orders. The expected set comes solely from determinant testing of every rectangle cell. This covers positive/negative step components, horizontal and vertical lines (A or B zero), primitive/nonprimitive directions, integer points at boundaries, no-solution rectangles, single-cell rectangles, endpoints outside rectangles, and signed ceiling/floor behavior. Separately check the inserted-row/column invariant before accepting the production shortcut that skips horizontal/vertical old pairs. Equal endpoints are invalid helper input and must fail or be explicitly rejected by its caller.

## Source and lifecycle review

Check the exact two-class completeness argument; threshold intervals partition all n+1 gaps once even when source coordinates repeat; zero-determinant old rectangles and affine new-point lines use mapped coordinates; uniform-translation regions are skipped only after source validity; excluded corners are never scored or stored as experiment results; all bit-clearing and first-certificate writes are consistent; and early completion means certificate-complete exclusion rather than a full score census.

Review stated ceilings against the actual loops, including precomputation and signed-line enumeration, and account for Python memory overhead. Confirm deadline checks during precomputation, triple/pair progress, extraction of certificate hits, validation, final pin verification, and saving. A completed valid target must be saved promptly; final pin or deadline failure must not claim complete family closure. Source/input/output identities must bind the selected source and exact gap family. No worker may launch a follow-on search, revive the four curtailed cases, or substitute a changed source/pool after a negative.

Author source/tiny evidence and independent comparison must precede any request to Root for a bounded actual pilot. This plan and the oracle's own self-consistency result are not a production-worker PASS. The separate lifecycle and prior-scope reviewers retain their review roles.
