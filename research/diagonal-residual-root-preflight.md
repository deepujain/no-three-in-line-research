# Standalone residual root-only preflight

Initial source/tiny stage is followed by actual n9 and n79 root-only gates; both passed and were independently audited. Receipts are in data/experiments/resume-residual-root-{n9,n79}-v1.json. This does not establish deeper search speed. The new `research/diagonal_residual_root_preflight.py` uses the unchanged owned-process helper, residual scanner, frozen control candidate function and secant state. No frozen core, guard, chain or dispatcher is edited. Source accepts strict integer n2..79, but Root must separately allocate each host operation, beginning with n9 only.

The worker creates exactly one declared singleton root `(diagonal, diagonal)` with one explicit deficit, builds the canonical orbit list and calls `residual_scan` exactly once. There is no DFS, core `run`, checkpoint, continuation or counted node. It validates an unchanged complete geometry snapshot after the scan. When the residual verdict passes, it derives the same MRV row and lexicographic singleton/pair batches from the complete admissibility vector, compares the entire ordered batch list with frozen control `candidates`, and verifies the root remains unchanged again. When bounds reject, it records the exact violations and does not call the control candidate function. Acceptance means this operation completed correctly, regardless of whether that root's bounds passed.

The source/job/report manifest binds the residual core and references, frozen control, state dependencies, unchanged helper and this actual standalone entrypoint. A new output directory prevents overwriting earlier observations. A strict bounded job with raw SHA-256 passed out-of-band declares n, deficit, diagonal, complete source hashes and an absolute host-monotonic worker deadline. The deadline includes child imports and retains one second before the supervisor's overall limit. JSON is bounded to 16 KiB, depth five, rejects duplicate keys and nonfinite constants, and numeric declaration fields reject booleans. Worker reports have exact keys; parent checks root declaration, zero nodes/no search, demands/degrees/edge arithmetic, rule membership, one attempted and one completed scan, exactly all canonical edge tests, bounded selected domain/batch size, source/job hashes and timing shapes. Parent does no root geometry or model replay.

The supervisor starts its clock before module imports in CLI use and invokes the unchanged helper with the remaining allowance, never above 30 seconds or 256 MiB. Worker and parent use flag-only SIGTERM/SIGINT handlers. The frozen scanner checks the absolute deadline at its existing boundaries; cancellation flags are checked around complete old operations. External cancellation remains the helper's responsibility, and killed/partial work has no accepted root result. Positive RSS and cleanup samples, clean ownership cleanup, zero worker exit, no monitor/cleanup error, passing time/RSS limits and unchanged sources are all required. Report/root verdict alone cannot override a failed resource or publication result.

Helper sampling covers the supervisor and owned process tree during its own measured interval, including cleanup. It excludes parent setup, bounded report checks and final report writing. Saved `elapsed_seconds` ends before that report write; the source-bound stdout summary adds `invocation_seconds` through final report durability and signal restoration, excluding summary emission. Neither is a hard filesystem deadline. Late deadline/cancellation/source faults clear the accepted result and rewrite a rejection when possible. A failed final write can leave report bytes; a consumer must require a successful supervisor exit, accepted report and unchanged independently pinned sources. Preserve stdout and stderr with the report for independent audit; do not infer success from a leftover file.

Eight focused tests passed in 1.174 seconds. Geometry was only n3/n5: all 34 declared roots match the independent tiny assessor, exact one-scan/no-DFS behavior and control equality are checked, and fault tests cover bounded input, deadlines, cancellation, mutation, source/job/report/counter mismatches, helper failures, missing samples and publication failures. Every residual deadline boundary at one n5 root was interrupted without a returned partial verdict. The fake helper launches actual tiny children but supplies mock resource data, so it gives no actual-host RSS/cleanup evidence. The first test run exposed an incorrect harness assumption that n3 `(0,0)` passes the bounds; passing-root fault tests now use `(0,2)`. No scan defect was concealed by that correction.

```sh
  --n 9 --deficit 0 --diagonal 0 --seconds 10 --rss-mib 256 \

```

This command is documentation, not execution authorization. Independently pin the reviewed script and dependency hashes before launch and record the successful exit and full stdout summary. No performance advantage, deep-prefix cost, witness existence or exhaustion conclusion follows from a root-only operation.
