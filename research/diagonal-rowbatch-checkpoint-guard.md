# Guarded diagonal row-batch checkpoint core

This separate adapter stages a private copy of the row-batch checkpoint and invokes the unchanged owned-process helper, with a 30-second maximum and 256-MiB sampled RSS ceiling. The prior fast-DFS guard, checkpoint, chain and active frontiers remain untouched. It binds the row-batch core, tiny reference, checkpoint utilities, fast/original cores, verifier, helper, adapter and current shared entrypoint; an exclusive checkpoint flock, externally trusted expected digest, source checks, atomic witness publication and post-cleanup promotion follow the existing reviewed checkpoint guard's policy. Input n is limited to 2..79 and frontier reads are bounded to the core's 1,000,000-byte limit. The external gate and cleanup are sampled/cooperative; I/O and cleanup can overrun nominal limits.

A restoration-time timeout on a previously accepted checkpoint returns its unchanged trusted digest with zero new nodes. This adapter recognizes that outcome and reports `reconstruction_timeout` with no newly accepted or promoted checkpoint: the predecessor field still describes the earlier invocation. Other worker, guard, source, cleanup, cancellation or publication failures remain incomplete. A post-promotion gate failure records a published-but-unaccepted hash and clears acceptance; recovery requires a fresh trusted decision rather than automatic adoption. Atomic witnesses may survive a rejected invocation and remain individually dual-verified.

Fifteen tiny tests passed for guard, core and reference before dispatcher integration, including n=3/n=5 sliced child runs with the helper mocked, invalid identities and digests, oversized input, reconstruction timeout without promotion, source and cleanup failures, cancellation forwarding, and interruptions around checkpoint publication. The helper has separate tests, but these mocks are not real-host resource or signal evidence. The adapter received independent source approval. The isolated shared dispatcher route has now been added and awaits independent route review and real-host tiny initial/resume checks. No n=79 work was run.
