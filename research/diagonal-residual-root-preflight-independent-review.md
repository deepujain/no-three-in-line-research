The worker constructs a single declared root, executes one complete residual scan, compares all ordered batches against the frozen control when the bound passes, verifies state snapshots, and does not call either core's DFS `run` or write checkpoints. The parent binds a bounded job digest and complete source manifest, validates work counts and report structure, and requires a clean helper exit, resource and cleanup samples, source stability and deadline checks before acceptance. A new output directory isolates results. Cancellation and timeouts may interrupt old operations externally; partial work is not accepted.

The saved report elapsed time ends before final write; the returned stdout invocation duration extends through report durability and signal restoration. Consumers must retain the actual successful process exit and stdout as well as the report and independently checked pinned hashes. If final reporting fails, an apparently accepted leftover report alone is not evidence of success. Sampled RSS covers the helper interval, not all parent setup/report processing, and is not a kernel hard limit.
