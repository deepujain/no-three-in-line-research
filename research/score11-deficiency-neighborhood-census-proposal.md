# One-neighborhood census of the 157-point deficiency state

Status: design only. No implementation or n=79 evaluation is authorized by this document. Independent mathematical review and source/tiny review must precede a separate lead-owned allocation. The census is one finite neighborhood, not a component search or a nonexistence proof.

## Input and scope

Use exactly the best saved 157-point invalid state from the completed deficiency walk: the fixed source minus (78,78), reported score 5, effective source deletion 1, no additions. Pin and independently audit its exact saved bytes and normalized identity before the eventual run; verify its point count, axis degrees and score using both existing exact validators. Do not substitute a reconstructed state for a mismatching saved artifact. Pin the existing walker and its dependencies, without changing the walker. The reported score and state identity are an actual-run finding pending its independent actual audit, not evidence newly obtained by this proposal.

State A has 157 distinct cells on the n=79 grid, degree two on all but one row and one column, each of degree one. The allowed moves are exactly the walker's row relocation, column relocation and uncolored rectangle switch; no source-retention restriction applies to neighboring states. Enumerate all ordered move-class/cell attempts (row,p), (column,p), p in lexicographically sorted A: 314 attempts. Then enumerate every unordered pair of distinct cells in lexicographic combination order for rectangles: C(157,2)=12,246 attempts. A candidate may be reachable by more than one labeled attempt; histograms count attempts, not necessarily distinct resulting states. No further move or recursive search is included.

For each attempt, call the reviewed walker wrapper, which checks membership, bounds, cardinality and axes. A rejected move counts as illegal. For each legal move, use the exact integer triple-count delta and record the original score plus delta; independently verify that its inverse exists, returns the original point set and reports the negated delta. Relocations reverse by moving the one newly added cell on the same axis; rectangles reverse using the two newly added cells. The operation is a finite full census only if every scheduled attempt and inverse check completes. A mismatch is a failure, not a histogram entry or successful completion.

## Counts, incumbents and deadline

Maintain attempted, legal and illegal counts and signed-delta histograms independently for row, column and rectangle moves; each completed class obeys attempted = legal + illegal and sum(histogram) = legal. Also report strictly improving (delta < 0), neutral and worsening attempt counts. The aggregate complete result requires 314 relocation and 12,246 rectangle attempts; report class-specific visited prefix and counts on interruption. Histograms from a partial run describe only the visited prefix and cannot establish absence of an improvement anywhere in the neighborhood. No bound on other states, moves or paths follows even on complete exhaustion.

Persist each new strictly lower scored candidate as a standalone best-invalid certificate, with sorted points and the exact score, only after both independent validators agree on point count, normalized hash, validity, score and canonical conflict triples; explicitly check 157-point axis invariants. If a candidate is valid, save it immediately after both validators, even when the soft deadline passes during the second validator, and terminate with witness status. The exact current best is never inferred from partially validated state. Among equal minimum scores retain the earliest in fixed attempt order; record that order and the generating move. A validated but positive-score state is invalid, not a witness. The starting input is independently verified and identified in the report; absent strict improvement, no new incumbent is claimed.

One eventual owned run has a 25-second monotonic soft interval measured from process entry and the existing 30-second, sampled 256-MiB outer guard. Check time between attempts and before starting each expensive validator. If time runs out before a second validator, leave that candidate unclaimed and report a partial result. Once both validators finish, atomically save the result, including a valid witness even after the soft deadline. Report deadline, completion reason, exact input and implementation pins, per-class visited counts/histograms, verification outcomes, elapsed time and guard evidence. The outer hard stop can interrupt execution or persistence; no partial or missing file is a complete result. No checkpoint, automatic retry, extension, beam, descent or follow-on policy is authorized by this design.

## Required reviews and tests

The mathematical reviewer must verify move enumeration, inverse cases, count arithmetic, multiple-attempt treatment and the scope of negative claims. Before any actual allocation, implement a separate bounded census module; do not modify the walker. Independent source/tiny review must compare exact histogram and inverse behavior against determinant enumeration for exhaustive tiny states; test same-axis and occupied-cross rejection, occupied deficient intersections, collinear lines of four, duplicate resulting states, lexicographic order and ties, partial deadlines at each class, validator disagreement, atomic save and a late validated witness. Include source/fixture identity, success and failure paths, plus guard lifecycle tests. Pin the input, both validators, walker, census, tests, guard, reviews and evidence. A future owner may use the complete histogram to inform a separate descent or temperature design, but this census specifies no such policy.
