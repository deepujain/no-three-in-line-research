# Singleton migration n5 implementation contract

SOURCE ONLY until Root owns a separate gate. The unchanged specification is `singleton-migration-n5-source-tiny-spec-v1.md`, SHA-256 `e00ed95695cd77cd6986938557279755c3cd41a1fef940f642107e7f9260dcf3`. This implements only its already approved n5 fixture and 32 legal relocations. It does not load actual n75 data or expose an optimizer, repeat mode or candidate adoption.

Root accepted two implementation clarifications following independent specification review: the oracle may retain nine additional d values and reuse nine h values while comparing each destination; publication attempts have hard cap three, covering evidence, at most one candidate-or-witness, and failure. Every attempt is charged before encoding or creating a file, including a failed attempt. No counter resets occur.

`research/singleton_migration_n5.py` separates the adjacent-edge determinant producer, the independent primitive direction/intercept endpoint oracle, an independently ordered scalar minimum, a fresh base-vertex determinant candidate scorer and a fresh normal-form endpoint candidate scorer. The current line map is cleared before any candidate map is constructed, including exceptional paths. The independent oracle compares all d/c/h entries, the baseline and invariant sums; the scalar minimum checks every one of the 32 moves. Exactly one strict candidate may be built and independently checked for deletion/insertion and swapped row loads. Positive scores remain diagnostic; a zero is saved as a witness requiring separate acceptance.

Hard work ceilings are unchanged: 312 determinants, 72 pair keys, 144 incidences, 72 multiplicity recoveries, 360 endpoint visits, 64 scalar scores and 64 move-key comparisons. Geometric counters charge before coordinates or arithmetic. The fixed 72-byte fixture and canonical nine-point identity are authenticated before producer geometry. Manifest limits are 64 KiB, 64 entries and 1,024-character paths, rejecting duplicate keys and physical path aliases. Required entries include the exact fixture/specification, this note, source and physical interpreter. Root must also bind the independent source acceptance and reviewed guard. Source/runtime/input digests are streamed and checked before geometry and before/after the final evidence publication; the manifest itself is hashed externally by Root and included in the internal pin checks.

The proposed tiny command is `.venv/bin/python -m research.singleton_migration_n5 --manifest <frozen-manifest> --output <new-output-directory>` from the repository root, under Root's separate 10-second/128-MiB owned guard. Program work checks require less than seven seconds, normal persistence/source closeout less than nine, and failure persistence less than ten. File and directory fsync support successful durability claims. Failure, deadline, source drift, quota or scorer disagreement invalidates acceptance even if an evidence file already exists. Failure persistence is best effort within the owned deadline and remaining publication attempts; Root must preserve its outer failure receipt when process death or persistence failure prevents an internal one. No retry or second candidate is allowed.

Buffers are bounded by the nine-point input and sole candidate, the producer d9/c4/h36 arrays, oracle d9/h9, bounded best-move records, one at-most-36-key line map, a 64-KiB hash chunk, and bounded manifests/publications. JSON rendering temporarily copies these small structures. Evidence is capped at 64 KiB, candidate/witness and failure at 16 KiB each. These source limits do not prove process RSS or wall time; the owned finite gate is mandatory. Receipt acceptance requires clean owned exit/cleanup, unchanged identities, matching saved hashes and no failure artifact.

A future n75 version would need its own reviewed specification, exact accepted fixed snapshot, complete oracle/score bounds and separately authorized gate. This module deliberately rejects that input. The present experiment is the final distinct relocation family for this research line; completing it grants no broader research or iteration.
