# Fixed main-prefix pair and bounded lazy SAT

This is a proposed separately gated test, not an authorized host run. It loads the hash-pinned main checkpoint and accepted receipt through the read-only prefix parser, reconstructs the fixed depth-19 prefix in private packed state, and requires the exact 102-orbit mask and ordered ID/hash identities. No DFS traversal or frontier writes occur. Each of 5,151 orbit pairs must be checked before native solver construction. Each completed pair uses transactional first-orbit push, exact read-only second-orbit probe, rollback and full prefix snapshot comparison; interrupted or poisoned private state yields no result.

The SAT formula contains one variable per mask orbit, exact residual radius-degree constraints, and negative clauses for incompatible pairs; parallel radius edges remain separate. Decode every model and recheck all quotient degrees and 158 distinct points. The first exact determinant triple becomes a negative clause only when its three points belong to three distinct newly selected orbits; any other case fails closed because the single/pair scans should already exclude it. Record exact pair cuts and the point triples underlying up to 1,000 distinct lazy cuts. At that cap or timeout, the result is incomplete. Solver-reported UNSAT applies only to this fixed prefix and depends on the trusted native solver; it is not a standalone proof certificate. Any completed valid 158 candidate receives both exact validators and immediate atomic saving, including when the soft deadline passes during final validation.

Proposed worker command `.venv/bin/python research/near_quarter_prefix_pair_sat.py --output-dir <fresh-output-dir> --seconds 25`, under the existing owned 30-second / 256 MiB guard. Verify all pins in `data/near-quarter-prefix-pair-sat-source-pins.json` before and after, collect a fresh receipt and independently audit exact complete/partial status and cuts. The timer is joined before solver deletion; errors, timeouts and incomplete pair scans cannot become negative claims. No memory fit, runtime or search success is assumed. No host run or source-integration decision is authorized by this note.
