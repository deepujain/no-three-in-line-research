## Pure interfaces and evidence semantics

`threshold_intervals(coords,n)` returns inclusive intervals covering 0..n; an interval ends at each source value, so equality belongs to the shifted side. `mapped_point(p,c,r)` implements the stated map. `rectangle_mask(c0,c1,r0,r1,n)` uses bit index (n+1)*c+r. `clipped_line_points(p,q,bounds)` supports signed, horizontal and vertical infinite lines inside inclusive `(c0,c1,r0,r1)` bounds and rejects coincident endpoints. The kernel safely skips horizontal/vertical old pairs using the inserted-axis invariant.

`cover_family(points,n,exclude_corners=True,deadline=None,*,check=None,counters=None,exhaustive=False)` canonicalizes source indices to lexicographically sorted points. It returns `included`, `uncovered`, `old_blocked` and `new_blocked` integers; a gap-keyed `certificates` dictionary with kind `old`/`new` and original source indices; and explicit `old_complete`, `new_complete`, `geometry_complete` and `certificate_complete` flags. Class masks are partial unless the matching complete flag is true. `exhaustive=True` is available for independent synthetic class-mask comparison. The CLI uses the default early full-cover stop.

A full cover is independently reconstructed through `verify_obstructions` before the kernel returns. It checks each included removed bit against one distinct collinear old triple or new-point/old-pair triple, rejects absent/extraneous records, out-of-range/duplicate source indices and malformed kinds, and requires omitted gap records to be empty. Early full coverage is certificate-complete exclusion, never a complete score census. Remaining gaps are eligible for candidate construction only if both geometry classes are complete. Partial coverage with unexcluded bits is inconclusive.

The report field `complete` means that the bounded experiment reached an accepted result (a verified family obstruction cover or saved dual-validated witness) and passed final deadline/identity checks. It does not imply all source triples or pair rectangles were visited. `geometry_complete` reports that distinction; `score_census_complete` is always false because the worker does not count all conflicts. A saved witness may survive a later timeout or pin failure, but those failures clear `complete` and `closure` and require independent assessment of the saved artifact.

## Work, memory and lifecycle caps

At most 6,352,752 old-triple rectangle determinants are tested after the four uniform products are skipped. At most 97,902 pair rectangles and 2,447,550 lattice points are visited. Runtime assertions enforce these bounds. One first-obstruction record is assigned per included gap, at most 5,621. The compact internal bytearray has exactly 22,500 bytes at n74. Its decoded gap-keyed certificate dictionary, JSON report, source points, validators and containers add bounded Python overhead; the compact table is not a claim about total RSS.

Column masks use at most 2,850 big integers of at most 5,551 bits plus 75 lists of 75 references. Rectangle/uncovered masks are at most 5,625 bits. A typical 30-bit-digit CPython mask is under 0.8 KiB, giving roughly 2.2 MiB for mask objects plus containers; decoded certificates and serialized output add several MiB at most in this bounded family. Actual process RSS must be measured by Root's unchanged 30-second / 256-MiB owned guard. These estimates and operation ceilings do not guarantee completion within 25 seconds.

The worker creates no process or thread. `ENTRY_STARTED` is captured before its remaining imports; the CLI's at-most-25-second cooperative budget includes imports, initial manifest and source validation, all geometry, certificate verification, candidate validation, pin hashing and publication. Checks run during source validation, each mask precomputation interval, geometry traversal, first-record extraction, each certificate slot, and each hashed MiB. Final report persistence is followed by a deadline check and correction if it crossed the deadline. The owned guard covers native validators and mandatory persistence that cannot be interrupted cooperatively.

A candidate's first validator must finish before the second begins. After the second returns a matching valid normalized identity and 149 points, the atomic witness save occurs before any optional deadline or pin check. File write, fsync and rename failures leave no accepted saved flag. Final source-pin or deadline failure clears completion and closure; final identity validity is false if pins could not be fully rechecked. The output directory must be fresh (`mkdir(exist_ok=False)`). The CLI prints only a compact result/counter summary to avoid a large certificate on its owned log.
