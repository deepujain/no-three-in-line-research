# Restricted paired-color half-turn walk

For odd n, store a permutation π and derive σ(r)=n−1−π(n−1−r). Reject any π(r)=σ(r). The 2n distinct points have degree two in every row and column and are half-turn invariant. This is a strict subfamily of degree-two half-turn symmetric states: an invariant 4-cycle can have its two alternating matchings individually preserved by half-turn. The counterexample is structural; it does not assert a valid no-three-in-line example.

Swap any two π rows, derive σ again, and reject overlaps. The same swap reverses the move. It is a simultaneous rectangle switch and its half-turn image, potentially with cancellations: at most four points are removed and four added. Compute set differences, remove old points one by one, subtracting the number of pairs collinear with each removal; add new points one by one, adding the corresponding count. This counts each affected triple once. Current state, best state and per-move temporary data are bounded by n, not iteration count. Final verification can materialize O(n³) conflicts; no O(n²) bound is claimed for the full pipeline. There is no visited history. A nonzero best score is an invalid full search state, not an improved valid point count.

Try at most 32 seeded shuffled permutations, checking the deadline before each; choose the first legal one, or use π(r)=(r+1) mod n as a fallback. Report the initializer and initial score. Choose two distinct rows uniformly using the supplied deterministic RNG seed. Accept downhill or equal moves; accept an uphill move of delta d with probability exp(−d/4). After 5,000 proposals without a new global best, reset current state to the best and continue the RNG stream. An iteration cap makes the move sequence reproducible when the soft time limit does not intervene; wall-time runs may vary. Final best score is checked by both independent geometry validators. A future pilot is proposed as one 25-second soft loop under the existing 30-second, 256 MiB owned-process guard, including initialization and final checks; hard guard failure or unfinished reporting is not a mathematical result. No new pool or protocol is proposed. No n79 run is authorized before independent source and tiny-test review and lead allocation.
