# Independent review: residual graph necessary bounds

Reviewed proposal SHA-256 `783551865605c06cdd8ac3565b7570bae24e3b517346e2507c67e3ba86ca0d88`. The proposed degree, component parity, bipartite balance, and global and component anti-diagonal color-capacity rejections are sound necessary conditions for a coherent partial state in the stated reflection slice, provided the graph contains every individually admissible remaining orbit. I found no mathematical counterexample to the stated tests. This is a proof review, not source approval or measured evidence of benefit.

A completion supplies an exact residual degree b-factor: each remaining orbit consumes one unit at each endpoint, and deleting other future points from a valid completion cannot make that orbit inadmissible. No completion edge can cross a component of the complete graph; its selected edges therefore contribute twice the component's total edge count. A bipartite component additionally receives one degree unit on each side per edge. Each selected orbit contributes two points to its x+y line, so two orbits of the same sum would violate the geometry; color cardinality is consequently an upper bound on the number of completion edges, globally and separately in each component. Existing points on a sum also preclude adding an orbit of that sum. These tests remain necessary even though individually admissible edges may conflict with one another.

The three strictness examples check out as abstract graphs, including the K(2,2) sums {2,3,4}; they do not show those graphs arise from reachable geometric states. The existing `candidates` implementation scans each deficient row and selects the smallest viable count, so a separate per-row shortage check can detect a row needing two edges when another row has one viable edge and needs only one. The claimed gains in real search are still unmeasured.

Implementation must preserve the proof's boundaries: build the complete graph including isolated positive-demand vertices; deduplicate an orbit seen from both endpoints; reject only after a completed scan; evaluate color capacity from admissible edges, not a sampled subset; and handle B=0 as a leaf. The planned independent determinant oracle, exhaustive tiny prefix and abstract graph checks, interruption tests, state immutability, and exact witness-set/order comparisons are appropriate prerequisites. Timing must include construction, graph passes, and reconstruction; fewer nodes alone is not a speed result. Source identity and frontier compatibility require separate review before any integration. No new numerical run or frozen-source change was made for this review.
