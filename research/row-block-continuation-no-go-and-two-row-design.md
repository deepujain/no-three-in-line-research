## Exact two-row reduction

Choose distinct rows r<s and remove all their points, leaving R. Let A_x=(x,r), B_y=(y,s). Define u_x and v_y as the numbers of triples created by adding the respective single point to R. Define C_xy as the number of retained points q with det(A_x,B_y,q)=0. For selected column sets X,Y, the exact final score is

    U(R) + sum(x in X) u_x + sum(y in Y) v_y + sum(x in X,y in Y) C_xy.

The terms account respectively for no-new, one-new and two-new triples. A two-new triple from the same row is impossible with a retained off-row point. Every three-new selection from two rows includes two points on one row and a third on the other, so cannot be collinear. Thus there is no omitted all-new or higher interaction. The diagonal entries C_xx are essential: vertical pairs are legal choices and can produce triples with retained points. Do not forbid equal columns across the two rows.

Compute U(R), u and v from the complete current pair-line index after masking out both rows: each retained line of occupancy t contributes C(t,3) to U(R), and contributes C(t,2) at its exact in-grid integer intersection with each empty row. Horizontal lines contribute no insertion cost. Every retained pair line already occurs in the full current index, so no separate retained-pair geometry census is required.

Construct C in O(n*|R|). For each A_x and retained q=(qx,qy), its line reaches row s at

    y = [x*(qy-r) + (qx-x)*(s-r)] / (qy-r).

The denominator is nonzero because R excludes row r. If the numerator is divisible by the denominator and y lies in[0,n-1], increment C_xy once for that retained point. Count all retained points on a shared line; they represent distinct mixed triples. Negative denominators and vertical intersections require exact signed integer division, not floating point. Direct determinants independently test this construction in the tiny evidence below.

For fixed X, define d_y=v_y+sum(x in X)C_xy. The optimal Y of prescribed size b consists of the b smallest `(d_y,y)` entries, with its selected columns sorted. There are no within-B interactions. Enumerate all X of size a, compute that optimal Y in a single O(n) scan, and choose the minimum tuple `(final_U, X, Y)`. A size-two selection needs the two smallest distinct entries, not an O(n log n) sort in production; each column appears once in the scan. A singleton uses the smallest entry. This reduces the2/2 neighborhood from C(n,2)^2 candidates to C(n,2)*n column-cost evaluations. Current coordinates are among the feasible choices. If their score ties the optimum, no transition occurs because acceptance requires strict improvement.

For two full rows, use load orientation(a,b)=(2,2). If one selected row is deficient, their total is three: solve BOTH orientations(1,2) and(2,1), regardless of which row was initially deficient, then choose the same minimum tuple across both. This permits moving the deficiency. Cells within a row must be distinct; columns across rows may coincide. No row pair has two initially deficient rows. Single-row optimization retains its current load, includes its current choice, and chooses `(result_U, sorted_columns)` deterministically.

At each current state, compute I_r, the number of old triples containing a point in row r. A violated nonhorizontal line with t points contributes C(t-1,2) to each member row. Row capacity at most two excludes horizontal violations, so every such line has at most one point per row. A row with I_r=0 cannot yield strict raw improvement by itself, because removing it destroys no old triple and additions have nonnegative costs.

Stage1: order rows with I_r>0 by `(-I_r,r)`. Evaluate each selected row's exact minimum, current included. On the first strict improvement, accept that minimum, rebuild and check the entire state score, then restart Stage1 on the new state. If every eligible row has been completely evaluated without improvement, the current state is an exact single-row local minimum; only then enter Stage2. An interrupted or capped sweep cannot receive that label.

Stage2: compute J_rs, the number of old triples meeting both rows. For each violated line containing rows r,s, add t-2 to J_rs. The exact number removed by deleting rows r,s is M_rs=I_r+I_s-J_rs. Rank all unordered pairs with M_rs>0 by `(-M_rs,r,s)`; pairs with M_rs=0 cannot strictly improve raw score. The arrays have75 row entries and at most2775 unordered pair entries. The total per-line pair-incidence work is bounded by the current point-pair count11026. Evaluate pairs in this fixed order using the exact reduction and all legal load orientations. On the first strict improvement, accept its exact minimum, rebuild and check score/axis invariants, then return to Stage1. If a pair fails to improve, continue to the next pair. There is no random tie-breaking, no forced different choice on a tie, and no retry with another pair ordering.
