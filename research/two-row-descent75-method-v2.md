## Geometry and deterministic policy

The current sorted point set has a complete primitive integer pair-line index with149-bit membership masks. Raw U is the sum of C(t,3) over its lines. Violations contribute C(t−1,2) to each member row's I, and t−2 to each member row-pair's J; M=I_r+I_s−J_rs. Horizontal violations are impossible under the hard row loads. Positive-I rows are ordered `(-I,r)`, positive-M pairs `(-M,r,s)`.

A single-row optimization removes that row, computes retained U and unary insertion costs by masking the complete index, and streams all current-included one/two-column choices in lexical order. A two-row optimization similarly computes retained U and two unary vectors, then constructs the75×75 byte cross matrix using exact signed divisibility. Every retained collinear point contributes, including vertical diagonal entries. For fixed outer X the one/two smallest distinct `(adjusted_cost,column)` entries choose the least tied partner Y in one pass. Four-point blocks stream size-two X. Three-point blocks merge singleton X then all pairs beginning at that column, preserving global `(U,X,Y)` order across both load orientations. The first completely scored zero is an exact global minimum by nonnegativity and that lexical order. `enumeration_complete=false` records the early exit separately from optimum established.

Stage1 commits the first strict row improvement, verifies a complete rebuilt positive score, then restarts. Only a complete failed positive-I sweep sets `row_sweep_complete`. Stage2 follows a complete Stage1 sweep and commits the first strict pair improvement, again restarting Stage1. It sets `pair_scan_complete` only after every positive-M pair fails. These are source-supported execution flags, not independent actual neighborhood certificates. Counter totals or terminal labels alone do not prove a local minimum, and none establishes global impossibility.

Started caps512 rows and32 pairs are global across every accepted state. An interrupted operation stays charged; a partially scanned positive minimum never commits. Cooperative checks run inside index, priority, retained-line, cross-intersection and column loops. A positive transition commits only after full invariant/score reconstruction and a final cooperative check. The controller returns the last complete boundary on interruption/error.
