# Independent design review: replacement-domain existence guarantee

Verdict: the stated existence-preservation theorem is valid for the stated row-valid setting and exact full-score, same-load one-row replacements. This is a proof/design review only: no input, fixture, geometry or search was constructed or evaluated. Reviewed assessment `research/four-row-overlap-predetermined-fixture-assessment-v2.md` SHA-256 `f03402515dd7f8c0fcd4669a9052b69806e14e802de00b2193128a4b776e3673`.

For any strictly improving same-load replacement in row r, the exact minimizer B_r is at least as good because the current assignment and all same-load subsets are included. A strict decrease requires at least one old conflict involving r: triples outside r remain fixed and newly introduced conflicts have nonnegative count. With at most two points per row, a conflicting triple cannot contain two points in one row, so one removed conflict occupies three distinct rows and supplies a current K-positive block containing r. The domain union contains B_r in r and each unchanged current assignment in the other rows; the block has the same legal loads and reproduces the strictly improving one-row state. This proves existence in some eligible block, not that a bounded prefix visits it or that the block optimizer chooses that particular replacement. Therefore exhaustion of every eligible block under these domains would exclude strict same-load one-row replacements only. It does not exclude a singleton migration, arbitrary three-row improvements, future states, or unrestricted/global minima, and it does not establish that the actual score-64 state exhibits the limitation.

The four-row face condition is sufficient to show a strict common-domain improvement changes all four rows: any improvement leaving one selected row unchanged would belong to that face. The separate comparator against every original K-positive triple is required to distinguish a structural route from a changed-domain effect. Neither condition supplies an instance or proves that a legal separating instance exists. No positive fixture should be manufactured or assumed as a prerequisite to review.

The smallest useful later diagnostic is one separately authorized, independently frozen row-valid n5–8 input and purpose, with U≤65 if the original production selector is compared. First run only the basic existence check: direct exact baseline and all same-load row placements, lexical B_r choices, K-positive conflict containment and unchanged-other-row reconstruction, cross-checked with an independent exact line oracle. It uses at most 204 placements plus one baseline and eight embedded checks, 213 scored states, 96,915 determinant tests and 22,365 line-pair constructions. An input with no strict row winner is a valid negative diagnostic, not a test failure or reason to choose another input. If the basic check finds a strict winner and a new domain-route witness is specifically sought, the separately authorized stronger comparator must check every original eligible triple; its additional 24,192 assignments bring the stated ceiling to 24,405 scored states, 11,164,755 determinants including unary work, and 2,562,525 line-pair constructions. Arithmetic was checked independently. No actual timing or memory forecast follows.

No instance, oracle execution, domain widening, continuation or retry is authorized by this review. A failed, interrupted or negative one-input diagnostic stops without adapting or replacing that input. A positive tiny case would support a subsequent design decision, not an actual-state conclusion or a four-row-necessity claim.
