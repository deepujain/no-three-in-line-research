# One bounded small-cut measurement on reachable prefixes

Design only. Propose one Root-owned evaluation under a five-second/256-MiB owned gate, with a four-second soft budget including source/evidence loading and all reconstruction. Source and tiny tests require independent review first. No experiment has been run for this proposal.

Use the accepted immutable main-diagonal and middle-diagonal frozen checkpoint/receipt identities. Bind their exact hashes and previously accepted audit linkage. Parse each selected root-to-active path with the existing bounded checkpoint parser. Do not resume a checkpoint or invoke DFS. Reconstruct its selected orbits in a fresh private PackedOrbitState, verifying every push succeeds. This is fresh reconstruction of known reachable prefixes, not exploration of new branches. Read original artifacts only; never write a chain head, checkpoint, receipt or existing report.

Choose exactly three depths in advance for each path: diagonal-only, floor of half its selected-four-orbit depth, and its deepest selected prefix. Deduplicate coincident depths. At most six prefixes are evaluated. Build one full exact individually admissible four-orbit mask per completed prefix using the frozen read-only probe. This mask includes every declared unselected orbit, regardless of any DFS cursor. Reconstruct existing global orbit shortage, row optimistic capacity, component parity and bipartite-balance verdicts from that same mask. Then call the reviewed pure small-cut helper on the corresponding full radius multigraph, preserving parallel edges and the central half-demand mapping. No rejection is fed back into traversal.

Record selected orbit IDs and point digest, complete-mask digest, demands/edge multiplicities, each old verdict, small-cut verdict, and separate nanosecond timings for mask construction, old bounds and cut. For a cut hit, retain its subset and d(U), e(U), outside demand, and cut-edge count so the inequality can be independently audited. A useful added rejection is a cut failure where all old conditions passed. Report both absolute cut cost and its fraction of mask-plus-old-bound cost; a single noisy sample is not a speedup claim. Preserve no growing history.

Check the soft budget during construction and scans. An interrupted state or incomplete mask supplies no verdict. Return a structured partial report identifying completed and unstarted sample depths. The final receipt must distinguish deadline/guard failure from a completed negative sample. Pin source and input artifacts before/after and save fresh report/evidence only. The sampled RSS gate remains an empirical limit, not a peak guarantee.

Tiny tests should build known coherent n3/n5/n7 paths and compare captured complete masks with independent determinant admissibility, radius loads with orbit expansion, and old-mask verdicts with the frozen scanner where available. Include a nonempty feasible prefix; zero-demand and parallel-edge cases; every interrupted report boundary; and unchanged original-file bytes. No need to enumerate a new search family or design checkpoint migration. Fullmask and cut logic are already separately tiny-reviewed; test only this wrapper's reconstruction and evidence boundaries.

If no old-pass/cut-fail prefix is found, report zero added hits in this at-most-six-prefix sample and measured cost; do not infer global uselessness or authorize more search. A positive hit proves local added information but does not establish a net traversal benefit. Any later integration or new packed genesis requires a separately reviewed source and Root allocation. Genuinely unvisited prefixes would require a separate traversal authorization and are outside this proposal.
